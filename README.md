# CS401: Introduction to Advanced Studies I – Spring 2024

This repository contains all my coursework and programming assignments for **CS401: Introduction to Advanced Studies I**, offered at **Illinois Institute of Technology** during **Spring 2024**.

This course provides an accelerated, hands-on introduction to object-oriented programming and foundational data structures using **Java**. All programming exercises are aligned with the textbook:

> **Textbook**: *Object-Oriented Data Structures Using Java*  
> **Authors**: Nell Dale, Daniel T. Joyce, Chip Weems  
> **Edition**: 4th Edition

## Key Concepts Covered

This course builds foundational skills in both **object-oriented programming** and **data structures**, including:

- **Java Syntax and OOP Principles**  
  Classes, objects, inheritance, polymorphism, exception handling

- **Abstract Data Types (ADTs)**  
  Stacks, queues, linked lists, trees, maps, graphs, priority queues

- **Algorithm Design & Recursion**  
  Recursive methods, search algorithms, and sorting (merge, quick, selection)

- **Efficiency & Big-O Analysis**  
  Order of growth, time-space tradeoffs, recursive time complexity

- **Software Design Patterns**  
  Modularization, UML class diagrams, encapsulation, interface design

## Sample Topics from the Book

Some of the major chapters from the course textbook explored in this repo include:

- **Chapter 1**: Getting Organized – OOP foundations, UML, exceptions, arrays  
- **Chapter 2**: Stack ADT – Array vs linked implementations, postfix evaluator  
- **Chapter 3**: Recursion – Linked list recursion, fractals, Towers of Hanoi  
- **Chapter 4**: Queue ADT – Circular queues, palindrome checker, simulations  
- **Chapters 5–8**: Collections, Lists, Maps – Sorted arrays, linked lists, hashing  
- **Chapters 9–10**: Priority Queues & Graphs – Heap, DFS/BFS, shortest paths  
- **Chapter 11**: Sorting and Searching – Bubble, Merge, Quick, Heap sort
